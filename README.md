# OBS Widgets Collection 🎬

รวมชุด Widget สำหรับใช้ซ้อนทับภาพ (Overlay) บนสตรีมในโปรแกรมถ่ายทอดสด (OBS Studio / vMix / XSplit) พัฒนาด้วย **React + Vite** + **TailwindCSS** พร้อมระบบ API Proxy ภายในตัวเพื่อแก้ปัญหา CORS ผ่าน **Cloudflare Pages Functions**

## 📦 Widgets ที่มีในตอนนี้

### 1. 🌊 ThaiWater Level Widget (แจ้งเตือนระดับน้ำ)
วิดเจ็ตแสดงระดับน้ำปัจจุบัน เปอร์เซ็นต์ความจุตลิ่ง และสถานะความรุนแรง (ปกติ / เฝ้าระวัง / ล้นตลิ่ง) ดึงข้อมูลอัปเดตแบบเรียลไทม์จากระบบสาธารณะของ สสน. (ThaiWater)
- **URL พื้นฐาน:** `https://obs-widget.pages.dev/widget/thaiwater-level`
- **ลูกเล่น:** สามารถเปลี่ยนสถานีที่ต้องการแสดงได้ง่ายๆ ผ่าน URL Parameter
  - **ดูสถานีเดียว:** เติม `?station=เมืองปราจีนบุรี`
  - **ดูหลายสถานีสลับกัน (สลับอัตโนมัติทุก 15 วินาที):** เติม `?stations=สะพานณรงค์ดำริ,เมืองปราจีนบุรี,กบินทร์บุรี`
- **ฟีเจอร์:**
  - ดีไซน์กระจกโปร่งแสง (Dark Glassmorphism) กลมกลืนกับภาพวิดีโอกลางคืน
  - แสดงลูกศรสีเขียว/แดง เพื่อบอกเปอร์เซ็นต์การเปลี่ยนแปลงของระดับน้ำ
  - หากระดับน้ำแตะ 100% ตัวเลขจะเปลี่ยนเป็นสีแดงสดอัตโนมัติ

### 2. 🌧️ ThaiWater Rain Widget (ปริมาณฝนสะสม)
วิดเจ็ตแสดงปริมาณฝนสะสม 24 ชั่วโมง ดึงข้อมูลจาก สสน.
- **URL พื้นฐาน:** `https://obs-widget.pages.dev/widget/thaiwater-rain`
- **ลูกเล่น:** เติม `?province=ปราจีนบุรี` เพื่อระบุจังหวัดที่ต้องการดึงค่าเฉลี่ยฝนสะสม

### 3. 📢 Prachin Alert Widget (ตัววิ่งข่าวสาร)
วิดเจ็ตแถบสไลด์ประกาศข่าวสารและเตือนภัย ดึงข้อมูลจาก `prachin.space`
- **URL พื้นฐาน:** `https://obs-widget.pages.dev/widget/prachin-alert`
- ดึงประกาศล่าสุดมาแสดงผลและสลับข้อความไปเรื่อยๆ (อัปเดตใหม่ทุก 1 นาที)

## 🚀 วิธีการใช้งานบน OBS Studio

1. เปิดโปรแกรม OBS Studio
2. ในแผง **Sources** กดปุ่ม `+` และเลือก **Browser**
3. ตั้งชื่อ Source เช่น "Water Level"
4. ในช่อง **URL** ให้นำ URL ของวิดเจ็ตข้างต้นมาวาง
5. กำหนด Width และ Height เป็นค่าอะไรก็ได้ (ตัวหน้าจอ Widget จะปรับขนาดให้พอดีกับหน้าต่าง)
6. แนะนำให้ลบ Custom CSS ที่ OBS ให้มาแต่แรกทิ้งให้หมด เพื่อให้การแสดงผลสมบูรณ์ที่สุด

## 🛠️ สำหรับนักพัฒนา (Development)

### การเตรียมตัว
ติดตั้ง **Node.js**

### การรันเซิร์ฟเวอร์บนเครื่องตัวเอง (Local)
```bash
npm install
npm run dev
```

### การตั้งค่า Proxy เพื่อเลี่ยง CORS
เนื่องจาก API ของระบบบางตัวไม่มี Header รองรับ CORS สำหรับเว็บภายนอก โปรเจกต์นี้จึงใช้ **Cloudflare Pages Functions** (ไฟล์ที่อยู่ในโฟลเดอร์ `functions/api/`) เป็นคนกลางในการไปดึงข้อมูลมาให้ พร้อมกับแนบ Header `User-Agent` และ `Referer` เพื่อให้ผ่านระบบป้องกัน

### การ Deploy ขึ้น Cloudflare Pages
```bash
npm run build
npx wrangler pages deploy dist --project-name obs-widget
```
